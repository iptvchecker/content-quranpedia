# Quranpedia resource mirror

This repository preserves original Quranpedia.net resources used by iQuranHolder (حامل القرآن), with source credit, versions and checksums.

## Current archive

Source: [Quranpedia.net](https://quranpedia.net). Official dump version: **2026-10-07**. Resource: Al-Wahidi, book 2919, `asbab-book-2919.json.gz`. Its original compressed bytes were checked against the publisher's SHA-256 and byte count. `UPSTREAM-MANIFEST.json` is preserved as provenance; it lists other publisher files that are not necessarily mirrored here. `SOURCE.json` identifies the exact mirrored archive. The book's internal edition/license information is unchanged.

## License and updates

Read the preserved [publisher license](LICENSE.md). Republished datasets require crediting Quranpedia.net with a link and stating the dump version. Keep copies current through the publisher's changes endpoint, subject to review. Third-party works retain their own licenses.

Fetch source changes into a separate review branch. Validate checksums, version, original content and publisher terms before publishing an updated release. Any removal requires a deliberate maintainer decision; publisher obligations remain in force.
